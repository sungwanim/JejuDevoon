# 12: 지점 기후 추정 + 적합도 + 교차검증

**What to build:** 지점을 클릭하면 AWS 관측값을 고도 보정해서 추정한 기온 지표와 작목별 적합도가 지도에 나오고, 추정 오차(관측소 하나씩 빼는 교차검증)가 함께 보고된다. 지점 기온은 관측소 값에서 고도 효과를 빼고 보간한 뒤 지점 고도로 되돌리는 방식으로 추정하되 구체적인 보간 방법은 구현 시 정한다(근거: Ryu 외 2024, *Atmosphere*, 제주 AWS 보간 선행 연구). 지리 패키지의 기후 부분과 적합도 규칙을 소유한다. 읽을 것: `.scratch/jeju-agri-agent/spec.md`의 '데이터'와 '판단 주체'.
