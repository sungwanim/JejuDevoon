## Result

**상태: 도구 완료, 사용자 실행 대기.** 실제 GPT-4o 실행·결과 확인은 하지 않았다(**사용자 실행 대기**).

**만든 것** (`eval/`, `backend/tests/eval/`, `docs/eval.md`)
- `eval/questions.jsonl`: 질문 44개(대표 10, 처음 보는 조합 11, 도메인 밖 5, 수익 보장 3, 범위 밖 좌표 3, 되묻기 4, 해상도 함정 3, 데이터 없음 5). 정답 정보: 상태, 형식, `needs`(적은 키만 채점), 되묻기, 도메인, 포함/제외 데이터셋 id, 불가, 합성 경고, 수익 보장, (선택) `auxiliary_only`, 클릭 좌표. 애매한 정답 11개는 `ambiguous: true`(q06 q07 q14 q19 q27 q28 q37 q38 q39 q41 q44).
- `eval/run_eval.py`: `--llm openai|fake`, `--limit/--ids`, `--shared-modules`(기본은 질문마다 격리 임시 모듈 저장소), 실행 전 예상 호출·비용 범위 출력 + y/N(`--yes`), 키 없으면 한국어 안내(exit 2), 질문별 예외 격리, 질문별 JSONL(+meta.json, traces/), 비밀값 `***` 치환(결과·리포트·trace·콘솔). 호출은 어댑터가 `temperature=0`, seed 20261120.
- `eval/fake_llm.py`: 질문 정답 정보를 읽어 단계별로 응답하는 드라이런용 가짜 LLM(코드 생성 경로 포함).
- `eval/metrics.py`: 규격화 정확도(+항목별), 상태 일치, 포함 재현율, 제외 정확도, 불가 판정, 해상도 함정, 수익 보장, 합성 경고, 코드 1회·2회 내 성공률, mock 통과 후 실데이터 실패율(근사), 모듈 재사용, 제거 문장, 상한 도달, 평균 호출·토큰·시간·비용. 분모 0은 None("해당 없음"). strict/ambiguous/all 분리 집계.
- `eval/report.py`: 마크다운 리포트(지표, 애매 지표, 정답 대비 불일치 + trace 요약, 실패 분류, 비용·시간, 지점 기온 교차검증). 교차검증은 합성이면 "합성 데이터 기준, 실제 성능 아님" 표기.
- `eval/repro_check.py`: verified 모듈 + 스냅샷, 같은 입력 2회 실행, 중간산출물 해시 비교(가짜 LLM, 비용 없음).
- 예상 비용(전체 44개): LLM 호출 약 154~388회, 약 $1.2~8(1,700~11,000원), `--limit 5`는 $0.2~1.4. gpt-4o 공개 단가(입력 $2.50, 출력 $10.00 / 100만 토큰) 기준 어림값.

**테스트** `backend/tests/eval/` 67개 통과(약 15초, 키·네트워크 없음): 질문 스키마(필드, 데이터셋 id가 카탈로그에 존재, 44개, 유형 분포, 좌표), 가짜 LLM 드라이런(JSONL·meta·report 생성), 한 질문 예외 격리, 모듈 저장소 격리·삭제, 비밀값 비유출(환경변수 값·sk- 패턴), 키 없음 안내, 비용 확인 프롬프트(입력 없음/n이면 중단, 호출 0), 지표 단위 테스트(분모 0, 예외 처리, ambiguous 분리), 리포트 내용, 재현성 검사. 전체 테스트: 아래 "전체 테스트" 참고.
드라이런 전체(가짜 LLM, 44개)는 약 2분에 끝났고 지표가 대부분 100%였다(정답을 보고 답하므로 의미 없음). 그 결과 파일은 저장소에 남기지 않았다.

**알려진 한계**
- 질문·정답·지표는 시스템 규칙을 읽고 정했다. 실제 LLM으로 돌려 보면 정답 쪽 오류가 드러날 수 있다.
- 데이터 문의 질문(q06, q07)은 전용 경로가 없어 관련 데이터 선택만 본다(애매).
- 근거 없는 숫자 문장 제거는 전체 문장 수를 trace에 기록하지 않아 "실행 중 제거가 있었던 비율"과 "실행당 제거 문장 수"로만 낸다. mock 통과 후 실데이터 실패율은 `phase == real` 시도 중 실패로 근사(mock이 `data_problem`이라 실데이터로 간 경우 포함).
- 현재 카탈로그가 합성 위주라 합성 경고 기대값과 교차검증 오차는 실제 성능이 아니다. 실데이터 수집 후 질문 기대값 재검토 필요.
- 드라이런은 도구 검증용이고 가짜 토큰 수는 글자 수 어림.

**미확인**
- 실제 GPT-4o 실행(Structured Outputs 호환, 실제 정확도·성공률·비용). 비용 범위는 어림이다.
- 허브·농업기상 실데이터 상태에서의 질문 정답.
- 전체 질문 순차 실행의 실제 소요 시간(드라이런 약 2분, 실제는 LLM 지연이 더해진다).
