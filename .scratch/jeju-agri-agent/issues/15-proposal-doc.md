# 15: 기획서 15쪽 초안

**What to build:** 15쪽 이내 기획서가 평가 결과와 함께 정리된다. 읽을 것: `.scratch/jeju-agri-agent/spec.md`, `DESIGN.md`, `docs/agent-flow.md`, 평가 도구 리포트(13). 기획서 구성: 구현목표, 서비스 제안, Agent 개발 구성(참여자 역할·목표·Workflow, 사용 모델, Tool/API, 판단 및 자율 수행 범위), 데이터 활용 계획, 개발·탑재 계획(구현 범위, 기술 환경, UI 구성, 센터 실행환경과 외부 서비스 의존성).

**Blocked by:** 13

**Status:** ready-for-agent

- [ ] 위 5개 항목이 15쪽 이내에 들어가고 심사 배점 항목(주제 15, 필수 데이터 20, Agent 기술성 25, 편의성 25, 신뢰성 15)에 각각 답하는 내용이 있다
- [ ] Agent 구성에 플로우 그림, 도구 목록, **판단 및 자율 수행 범위**(Agent가 스스로 하는 것 / 규칙이 정하는 것 / 하지 않는 것)가 있다
- [ ] 평가 도구의 정량 결과와 교차검증 오차가 근거로 들어 있다
- [ ] 한계와 외부 의존성(OpenAI API, 공공데이터포털, 센터 PC 사양)이 숨김 없이 적혀 있다
- [ ] 수익을 보장하지 않는다는 점과 데이터의 한계(제주시 감귤 데이터 없음, 90m DEM 등)가 명시된다
- [ ] 인용한 논문(Data Interpreter, InfiAgent-DABench, Ryu 외 2024 등)의 서지가 정확한 원문 기준으로 적혀 있다
