# 제주 공공데이터 분석 Agent

제주의 여러 도메인(농업, 기상, 환경 소음, 도시숲 등) 공공데이터를 카탈로그로 받아, 도민의 자연어 질문에 맞는 데이터를 **Agent가 직접 탐색·선택하고 데이터 구조에 맞는 분석 코드를 작성·검증·저장·재사용**해 HTML 결과(보고서·그림·지도)로 보여 주는 로컬 웹앱입니다. 새 도메인의 데이터는 카탈로그에 항목만 추가하면 같은 흐름으로 분석됩니다. 백엔드는 FastAPI, 프런트엔드는 Vite + React, LLM은 OpenAI GPT-4o이며 Agent 흐름은 프레임워크 없이 Python 상태 머신으로 구현했습니다. 분석하는 동안 단계별 결정과 이유를 "생각 과정"으로 화면에 보여 줍니다.

> **이 프로젝트의 특징과 사용 전 참고**
> - **여러 도메인을 한 흐름으로:** 농업, 기상, 환경 소음, 도시숲 데이터를 같은 카탈로그에 두고, 질문에 맞는 데이터를 고른 뒤 데이터 구조에 맞는 분석 코드를 Agent가 직접 작성·검증합니다.
> - **실데이터만 사용:** 앱에는 합성(가짜) 데이터가 없습니다. 가격·기온은 허브 거래 통계·이동평균 API와 농촌진흥청 농업기상 일자료의 실데이터 스냅샷(`snapshots/live/`)이며, 스냅샷이 없으면 그 데이터셋은 목록에 나타나지 않습니다.
> - **판단 과정을 보여 줍니다:** 분석하는 동안 단계별 결정과 이유가 "생각 과정"으로 화면에 쌓이고, 결과마다 사용한 데이터, 제외한 데이터와 이유, 한계, 출처가 붙습니다.
> - **판정 범위:** 근거 데이터가 없는 재배 적합도, 한계온도(동해 등), 수익은 판정하거나 보장하지 않습니다.
> - **고도화 중인 영역:** 여러 작업을 잇거나 두 데이터를 합쳐야 하는 복잡한 질문은 계속 개선하고 있어 결과가 달라질 수 있습니다. 처음에는 아래 "처음 써 보기"의 질문으로 시작하세요. 실행 결과와 검증 내용은 `docs/submission/3_결과_설명자료.md`에 정리했습니다.

제출 문서는 `docs/submission/`에 있습니다: `0_기획서.md`(기획서), `1_실행환경_매뉴얼.md`(실행환경·사용자 매뉴얼), `2_데이터_활용_명세.md`(데이터 활용 명세, AI·API·오픈소스 선언 포함), `3_결과_설명자료.md`(결과 설명자료).

## 1. 권장 실행 환경

센터 Agent 운영 PC 최소사양(Intel Core i7-8700 / GTX 1060 / RAM 32GB)에서 돌리는 것을 기준으로 적었습니다. 이 앱은 GPU를 쓰지 않습니다(LLM은 OpenAI 서버에서 실행). 실제 이 사양의 PC에서 실행해 본 것은 아니며(미확인), 개발 PC(Windows 11)에서만 확인했습니다.

| 항목 | 요구 |
|---|---|
| OS | Windows 10/11 (개발·확인은 Windows 11). 다른 OS는 확인하지 않았습니다 |
| Python | 3.14 (개발 환경 3.14.8) |
| Node.js | 화면 코드를 고칠 때만 필요 (개발 환경 v24.21.0, npm 11.19.0). 실행만 한다면 불필요 |
| 네트워크 | OpenAI API 호출과, 결과 화면의 지도 타일·차트 라이브러리(CDN) 로딩에 인터넷이 필요합니다 |
| 키 | `OPENAI_API_KEY` 필수(실제 분석). 허브·공공데이터포털 키는 실데이터 수집 때만 |

## 2. 설치

저장소(또는 제출 zip을 푼 폴더) 루트에서 실행합니다. 아래는 PowerShell 기준입니다.

```powershell
# 1) 파이썬 가상환경과 의존성 (backend/requirements.txt)
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend\requirements.txt

# 2) 프런트엔드 의존성 (화면 코드를 고칠 때만. 실행만 한다면 건너뛰어도 됩니다)

npm ci
cd ..

# 3) 환경변수 파일 (키는 직접 입력. 채팅·문서에 붙여넣지 마세요)
copy .env.example .env
notepad .env
```

## 3. 환경변수

`.env`는 프로젝트 루트에 둡니다(`api/main.py`가 루트의 `.env`를 읽음). `.env`는 git과 제출 zip에서 제외됩니다. 키 값은 코드·문서·채팅에 남기지 마세요.

| 변수 | 필수 | 용도 | 비고 |
|---|---|---|---|
| `OPENAI_API_KEY` | 실제 분석에 필수 | OpenAI GPT-4o 호출 | 없으면 요청 시 "OPENAI_API_KEY가 없습니다" 오류 |
| `JEJU_HUB_PROJECT_KEY` | 실데이터 수집 때 | 제주데이터허브 API 프로젝트 키 | 키가 호출 URL 경로에 쓰이므로 예외·로그에 URL을 남기지 않게 처리됨 |
| `DATA_GO_KR_SERVICE_KEY` | 선택 | 공공데이터포털 서비스 키 | 농업기상(농촌진흥청) 제주 지점 일자료 수집에 씀(`collect agri-weather`). 수집하지 않으면 기온 데이터셋이 목록에 나타나지 않음 |
| `JEJU_DATA_MODE` | 선택 | `live`이면 허브 API 호출 + 실패 시 스냅샷 폴백. 비우면 스냅샷만 | `.env.example`에 있음 |
| `JEJU_LLM` | 선택 | `fake`이면 키 없이 화면만 확인하는 데모(단계 진행 화면만 확인) | 실제 분석 불가. 화면 확인용 |
| `JEJU_MODULE_STORE` | 선택 | 분석 모듈 저장소 폴더. `1`/`on`/`true`는 기본 `module_store/` | `api/main.py`는 `ModuleStore()`를 직접 연결하므로 웹앱 실행에서는 이 변수 없이도 `module_store/`를 씀 |

`.env.example`에는 `OPENAI_API_KEY`, `JEJU_HUB_PROJECT_KEY`, `DATA_GO_KR_SERVICE_KEY`, `JEJU_DATA_MODE`만 있습니다. `JEJU_LLM`은 필요할 때만 셸 환경변수로 지정합니다(`run-demo.bat`이 지정).

## 4. 실행

**가장 간단한 방법:** 프로젝트 루트의 `run.bat`을 더블클릭합니다. 서버가 `127.0.0.1:8000`에서 켜지고 브라우저가 자동으로 열립니다. 키 없이 화면만 보려면 `run-demo.bat`입니다. 사용자 PC에는 Python만 있으면 되고 Node는 필요 없습니다(화면은 `frontend/dist`에 미리 빌드되어 있고 백엔드가 같은 포트로 서빙합니다).

같은 동작을 명령으로 실행하려면:

```powershell
cd backend
..\.venv\Scripts\python.exe -m jejuagent            # --port 8001, --no-browser 옵션 가능
```

서버는 `127.0.0.1`에만 열리고 API에 인증이 없으므로 공용 PC나 원격 접속에서는 쓰지 마세요. 지도 타일(CARTO, OpenStreetMap 데이터)은 인터넷이 필요합니다. 포트가 사용 중이면 안내 메시지가 나옵니다.

키 없이 화면만 보려면 `JEJU_LLM=fake`로 실행합니다(`run-demo.bat`, 또는 PowerShell: `$env:JEJU_LLM="fake"` 후 같은 명령). 이때는 어떤 요청이든 "데모 모드라 분석하지 않는다"는 불가 응답으로 끝나며, 입력→단계 진행→결과 화면의 흐름만 확인됩니다.

6. 이상하면 `runs/<실행 id>/trace.json`에서 `decision` 이벤트의 `failure`와 `message`를 봅니다.

### 개발자용 (화면 코드를 고칠 때)

화면을 고친 뒤에는 **반드시 `cd frontend; npm run build`로 `frontend/dist`를 다시 만들어 함께 커밋**합니다(저장소에 빌드 결과를 포함합니다. 파일 이름에 해시가 붙어 매번 바뀝니다). 핫리로드가 필요하면 백엔드를 위 명령으로 `--no-browser`로 띄우고 `cd frontend; npm run dev`를 쓴 뒤 `http://localhost:5173`을 엽니다(`frontend/vite.config.ts`가 `/api`를 8000으로 넘깁니다).

### 스냅샷 모드와 라이브 모드

| 모드 | 설정 | 동작 |
|---|---|---|
| 스냅샷(기본) | `JEJU_DATA_MODE` 비움 | `catalog/`의 카탈로그와 `snapshots/`·`data/`의 파일만 읽음. 네트워크 데이터 호출 없음 |
| 라이브 | `JEJU_DATA_MODE=live` + `JEJU_HUB_PROJECT_KEY` | 허브 가격 데이터는 API를 호출하고 성공하면 `snapshots/live/`에 고정. 실패하면(키 없음·키 오류·한도·네트워크) 원인과 해결 방법을 안내하고 마지막으로 고정한 스냅샷으로 폴백 |

허브 거래 통계·이동평균과 농업기상 일자료는 실제 키로 호출해 확인했습니다. 오류 응답 형식은 명세 기준으로 구현했고, 허브는 인증 실패와 권한 없음이 같은 403 `Forbidden`으로 와서 구분하지 못합니다.

실데이터 수집(허브 거래·이동평균, 키 필요) — `backend/` 폴더에서:

```powershell
..\.venv\Scripts\python.exe -m jejuagent.data.live.collect hub 20150101 20251231
```

제주 기상 관측소 일자료(기온·강수) 실데이터 수집 — 농촌진흥청 농업기상(`DATA_GO_KR_SERVICE_KEY`, 관측지점 상세정보와 상세 관측데이터 두 API를 각각 활용신청). 제주 지점의 위경도·고도까지 자동으로 받고, 센서 오류로 보이는 값이 든 날은 뺍니다. 한도·오류로 멈추면 같은 명령을 다시 실행하면 이어받습니다:

```powershell
..\.venv\Scripts\python.exe -m jejuagent.data.live.collect agri-weather --days 20240101 20241231
```

## 5. 테스트

프로젝트 루트에서(키·네트워크 불필요, LLM은 가짜):

```powershell
.venv\Scripts\python.exe -m pytest backend/tests -q
```

격리 실행기(sandbox) 테스트가 길어(약 70~80초) 전체는 3분 안팎입니다. 영역별로는 `backend/tests/<영역>`(`runner`, `catalog`, `parse`, `selection`, `data`, `sandbox`, `analysis`, `modules`, `render`, `geo`, `climate`, `live`, `e2e`)을 지정해 돌립니다. 마지막 전체 실행: 283개 통과.

프런트엔드는 별도 테스트가 없고 `npm run build`(타입 검사 포함)만 확인합니다.

## 7. 오류와 제약사항

- **관측소 고도 범위:** 농업기상 제주 지점 16개의 고도는 18~208m라 한라산 고지대는 보간이 아니라 외삽입니다.
- **OPENAI_API_KEY 없음:** 분석 요청이 "OPENAI_API_KEY가 없습니다" 오류로 실패합니다. `.env`를 확인하세요.
- **라이브 모드 폴백 안내:** 키 없음·키 오류·한도 초과·네트워크 오류가 나면 결과에 원인과 해결 방법이 표시되고 스냅샷으로 동작합니다.
- **실행 상한:** 한 번 실행에 LLM 호출 25회, 5분. 걸리면 그때까지의 결과로 만들고 `partial`로 표시합니다. 코드 생성 작업은 작업당 최대 2회 시도(생성 + 수정 1회)이며 재계획은 없습니다.
- **인터넷 필요:** 결과 HTML의 차트·흐름도·지도는 CDN(jsdelivr, unpkg)과 지도 타일(CARTO)을 불러옵니다. 차단되면 차트는 "표로 보기", 지도는 좌표 표, 흐름도는 번호 목록으로 대체됩니다. 실제 브라우저에서 차트·흐름도의 CDN 렌더링을 눈으로 확인하지는 못했습니다.
- **채소재배현황:** 도 전체 단위, 조수입 기준(순이익 아님), 연산 15-16~20-21(기준일 2021-08-09)입니다. 허브 가격 품종과의 이름 연결은 월동무뿐입니다.
- **범위:** 제주 본섬(우도·가파도 포함 격자). 추자도·마라도는 범위 밖입니다. 지점은 지도 클릭으로만 지정합니다(주소·지명 검색 없음).
- **DEM:** 90m 격자 고도 조회뿐이며 경사·사면·일사는 반영하지 않습니다. 바다 마스크는 추정입니다(`docs/dem.md`).
- **판정하지 않는 것:** 한계온도로 재배 가능 여부, 재배 적합도, 수익. 감귤 생산 데이터는 서귀포시뿐입니다.
- **서버 재시작:** 진행 중 실행 상태와 되묻기 대화 상태는 메모리에만 있습니다(`runs/`에는 trace가 남음).
- **보안:** 단일 사용자 로컬 사용을 가정합니다. 생성 코드 실행기는 보안 샌드박스가 아닙니다. 외부에 노출하지 마세요.
- **저작권·귀속:** 결과물은 제주빅데이터센터에 귀속됩니다(대회 규정).
