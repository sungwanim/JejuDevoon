## 3. 결정 사항

- **LLM:** OpenAI GPT-4o 하나. Jev는 쓰지 않기로 함.
- **범위:** 제주도 본섬 전체. 추자도 등 제외.
- **데이터 원칙(엄격):** **공공데이터포털 데이터셋 + 제주데이터허브 데이터만** 쓴다. 문헌·PDF·논문·보도에서 옮긴 값은 쓰지 않는다.
  - 결과: `backend/jejuagent/criteria/criteria.json`(문헌 기반 재배 기준표)과 12의 적합도 규칙은 **기본 꺼짐**. 코드는 남겨 둠. 16 에이전트에게 지시했고 반영 여부는 16의 `## Result`에서 확인.
  - 결과 화면 한계 문구: "재배 적합도는 공공데이터셋 근거가 없어 판정하지 않음".
- **한계온도(동해 등) 판정은 하지 않는다.** 극최저기온·저온 일수는 참고 지표로만 표시.
- **DEM:** 국토지리정보원 90m, 용도는 지점 고도 조회뿐. 경사·사면·일사 모델링 없음. 바다 마스크는 추정(1m 초과 연결 성분 100칸 이상을 육지로 봄, 한계는 `docs/dem.md`).
- **재시도:** 작업당 코드 시도 2회(생성 + 실패 원인별 수정 1회), 재계획 없음. 수익 보장은 하지 않음.

## 5. 새로 생긴 기회: 채소재배현황으로 "이익" 지표 만들기

`제주채소류재배현황.csv`는 원칙 안(허브 데이터)에서 **면적당 조수입, 수량, 단가(=조수입/생산량), 재배면적 추세**를 계산할 수 있게 해 준다. 사용자의 원래 목표("뭘 늘리면 이익이 될지")에 가장 가까운 허브 데이터다. 다만:
- 도 전체 단위라 **지점별 차이는 설명하지 못한다**(지점 기후와 합치려면 가정이 필요).
- 비용이 없어서 **순이익이 아니라 조수입** 기준임을 반드시 표시.
- 작목 이름이 허브 가격 데이터의 품종 이름(월동무, 구마늘 등)과 다르므로 매핑이 필요.
- 최신 연산이 20-21이라 오래됨(기준일 2021-08-09). 한계에 표시.

다음 작업 후보: 카탈로그 항목 추가, `market` 모듈 시드(작목별 면적당 조수입·재배면적 추세), 시험지 질문에 포함.

## 6. 사용자가 해야 할 일

1. **API 키를 `.env`에 넣기**: `OPENAI_API_KEY`, `JEJU_HUB_PROJECT_KEY`, `DATA_GO_KR_SERVICE_KEY` (`.env.example` 참고, 키 값은 채팅에 붙이지 말 것). `JEJU_DATA_MODE=live`도.
2. **허브 거래 데이터 수집**: `cd backend` 후 `..\.venv\Scripts\python.exe -m jejuagent.data.live.collect hub 20150101 20251231`. 성공하면 합성 샘플 대신 실데이터가 우선된다.
3. **게시판 문의**(공식 답변은 게시판만): ① 외부 LLM API 사용 시 키·비용 부담, ② 허브 API만 써도 인정되는지·외부 공공데이터 병용 가능 여부, ③ "데이터 탐색"과 "Tool 사용"의 기대 수준, ④ 농업기상 관측데이터가 공공누리 제4유형(변경금지)인데 가공·분석 결과 사용이 가능한지.
4. 농업기상 **관측지점 정보 API 명세**와 생장도일 명세(HWPX/DOCX)를 `data/docs/schemas/`에 넣기 → 제주 관측소 목록 확인.
5. 감귤 적지 기준(2015 논문 vs 2017 논문)은 원칙상 문헌이라 **쓰지 않기로**. 감귤은 연평균기온 참고 지표만.

## 8. 알려진 위험·미확인

- **실제 GPT-4o 동작 미확인.** 프롬프트, Structured Outputs 스키마 호환, 코드 생성 성공률은 전부 가짜 LLM 기준 검증.
- **합성 데이터:** 현재 화면의 가격·기온은 합성이다. 08의 합성 경고 배너로 표시되지만, 제출 전에 실데이터로 바꾸거나 시연에서 반드시 설명해야 한다.
- 허브 API 실호출 미확인(응답 형식, 인증 실패·한도 초과 형식은 명세에 없음).
- 07: 재사용 시 같은 코드+같은 데이터 해시면 실데이터 실행을 건너뜀(spec은 재검증). 16이 조정했는지 `## Result` 확인.
- 생성 코드 실행기는 LLM 실수를 막는 장치이지 보안 샌드박스가 아니다(제출 문서에 명시).
- 소요일은 모두 추정. 남은 시간 대비 범위가 빠듯하다.
- **커밋이 하나도 없다.** `git add`/커밋은 사용자가 직접 해야 한다. 커밋 전 `.gitignore` 점검(`.env`, `.cache/`, `runs/`, `.venv/`는 이미 포함. `module_store/`는 미정).
- 문헌 출처(JIBS 보도, 논문 2편, 농사로 문서)는 원칙상 런타임에서 안 쓰지만 `criteria.json`에 기록으로 남아 있다. 기획서 한계 절의 근거로만 활용.
