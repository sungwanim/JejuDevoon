# 단일 실행 직접 테스트 가이드

`run.bat` 더블클릭 하나로 앱이 열리는지 확인하는 체크리스트입니다. 키 없이 시작해서 필요한 부분만 키를 넣어 봅니다. 소요 약 15분.

## 0. 준비

- Python 3.14와 루트의 `.venv`가 있어야 합니다(없으면 `README.md` 3절의 설치 단계). **Node는 필요 없습니다.**
- `frontend/dist` 폴더가 있는지 확인합니다(저장소에 포함되어 있음).
- 포트 8000을 쓰는 다른 프로그램이 없어야 합니다.

## 1. 키 없이 켜기 (데모)

1. 루트의 `run-demo.bat`을 더블클릭합니다.
2. 검은 창이 뜨고 `http://127.0.0.1:8000/` 안내가 보입니다.
3. 기본 브라우저가 자동으로 열립니다.

- [ ] 브라우저가 자동으로 열리고 제주 지도 화면이 보인다
- [ ] 지도 타일이 보이고, 클릭하면 마커와 좌표가 표시된다 (인터넷 필요)
- [ ] 입력창에 `주식 추천해줘`를 보내면 "제주 농업·기후·시장 데이터 분석과 관련 없는 요청" 취지의 거절이 나온다
- [ ] 브라우저 주소가 `127.0.0.1:8000`이고 `localhost:5173`이 아니다 (Node 개발 서버를 쓰지 않음)

검은 창에서 `Ctrl+C`로 끕니다.

## 2. 시나리오가 있는 데모 (선택)

지도 클릭 + 결과 화면(합성 경고, 지도, 차트) 확인은 `docs/TESTING.md` 2절을 따릅니다. 서버를 띄운 뒤 `http://127.0.0.1:8000`을 엽니다.

## 3. 실제 키로 켜기

1. 루트 `.env`에 `OPENAI_API_KEY`를 넣습니다 (`.env.example` 참고, 키는 채팅에 붙이지 마세요).
2. `run.bat`을 더블클릭합니다.

- [ ] 1번과 같이 화면이 열린다
- [ ] 지도 클릭 후 `여기에 월동무 어때?`를 보내면 단계가 진행되고 결과가 나온다 (시나리오별 기대 결과는 `docs/TESTING.md` 3절)

## 4. 오류 상황

| 상황 | 하는 법 | 기대 결과 |
|---|---|---|
| 포트 사용 중 | `run-demo.bat`을 켠 채로 `run.bat`을 한 번 더 실행 | "포트 8000번이 이미 사용 중입니다..." 안내 후 `pause`로 멈춤 |
| 다른 포트 | PowerShell: `.\run-demo.bat --port 8001` | `http://127.0.0.1:8001/`로 열림 |
| 브라우저 자동 열기 끄기 | `.\run-demo.bat --no-browser` | 서버만 켜지고 브라우저는 안 열림 |
| 화면 빌드 없음 | `frontend\dist` 폴더 이름을 잠깐 바꾸고 실행 | `/`에 "화면이 빌드되지 않았습니다 ... npm run build" 메시지(JSON). `/api/catalog`는 정상. 확인 후 이름을 되돌림 |
| `.venv` 없음 | `.venv` 이름을 잠깐 바꾸고 실행 | PATH의 `python`으로 시도. 모듈이 없으면 "실행에 실패했습니다" 안내. 확인 후 되돌림 |

## 5. 외부 접속 차단

- [ ] 서버를 켠 채 PowerShell에서 `netstat -ano | findstr :8000` → 주소가 `127.0.0.1:8000`이다 (`0.0.0.0:8000`이면 문제)
- [ ] 같은 와이파이의 다른 기기에서 내 PC IP:8000으로 접속이 안 된다 (가능하면)

## 6. 제출 zip 확인

```powershell
.venv\Scripts\python.exe scripts\make_submission.py
```

- [ ] 마지막에 "비밀값 없음" 취지의 메시지가 나온다. 이메일 형태 문자열 경고 3건은 알려진 항목(`user@example.com` 등 테스트용)이라 무시해도 된다. 확인하지 못한 것: `report.html.j2`와 `test_render.py`의 매치가 같은 가짜 주소인지
- [ ] 출력된 zip 경로를 풀어서 `run.bat`, `run-demo.bat`, `frontend/dist/index.html`이 있고 `.env`, `node_modules`는 없다
- [ ] 풀어낸 폴더에서 Python 환경을 새로 만들고 `run-demo.bat`을 실행해도 화면이 열린다 (Node 없이)

## 7. 자동 테스트

```powershell
.venv\Scripts\python.exe -m pytest backend\tests\api -q      # 정적 서빙 3개, 약 10초
.venv\Scripts\python.exe -m pytest backend\tests -q          # 전체 269개, 약 3분
```
