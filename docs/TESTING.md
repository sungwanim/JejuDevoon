# 직접 테스트하는 방법

이 문서는 사용자가 직접 앱을 돌려 보고 문제를 찾는 순서를 적었습니다. 명령은 모두 **프로젝트 루트(`everyoneJeju`)에서 PowerShell**로 실행하는 기준입니다. 설치와 환경변수의 자세한 설명은 `README.md`를 보세요.

> **먼저 알아둘 것**
> - 지금까지 모든 자동 테스트는 **가짜 LLM**으로만 돌았습니다. 실제 GPT-4o로 돌려 보는 것이 이 문서의 핵심 목적입니다. 실제로 돌리면 프롬프트·스키마 문제나 엉뚱한 데이터 선택이 나올 수 있고, 그게 정상적인 발견입니다.
> - 가격·거래·기온 데이터는 **합성 샘플**입니다. 결과 화면 맨 위에 붉은 경고 배너가 뜨는 것이 정상입니다.
> - 지도·차트·흐름도는 결과 HTML이 **인터넷(CDN)** 에서 라이브러리를 불러와 그립니다. 실제 브라우저에서 제대로 그려지는지는 아직 아무도 눈으로 확인하지 못했습니다. 이 부분을 꼭 봐 주세요.

---

## 0. 준비 (한 번만)

```powershell
# 파이썬 환경이 없으면
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend\requirements.txt

# 프런트엔드 의존성 (화면을 빌드할 때만 필요. 실행·데모만 한다면 건너뛰기)
cd frontend
npm ci
cd ..

# 키 파일 (OpenAI 키는 5번 이후에 필요)
copy .env.example .env
notepad .env
```

`.env`에 `OPENAI_API_KEY=` 뒤에 키를 넣으세요. 키는 채팅이나 문서에 붙여 넣지 마세요. `.env`는 git에 올라가지 않습니다.

## 1. 자동 테스트 (키 없이, 약 3~4분)

```powershell
.venv\Scripts\python.exe -m pytest backend/tests -q
```

- 마지막 기록은 199개(티켓 17) 이후 평가 도구 테스트 67개가 추가된 상태입니다. 전체를 한 번에 다시 돌린 적은 없으니, **전부 통과하는지 먼저 확인**하세요.
- 느리면 영역만: `.venv\Scripts\python.exe -m pytest backend/tests/e2e -q`
- 실패하면 어떤 테스트가 실패했는지 이름과 메시지를 저에게 보내 주세요.

프런트엔드 빌드 확인: `cd frontend; npm run build; cd ..`

## 2. 키 없이 화면 먼저 보기 (데모 서버)

실제 LLM 없이 **화면 동작**만 확인하는 방법입니다. 시나리오가 고정된 가짜 응답이라, 질문 문장을 바꿔도 같은 흐름이 나올 수 있습니다.

시나리오가 들어 있는 데모 서버를 `backend/`에서 띄웁니다. 화면은 빌드된 파일을 같은 포트로 서빙하므로 터미널 하나면 됩니다.

```powershell
cd backend
..\.venv\Scripts\python.exe -m uvicorn demo_app:app --app-dir tests/e2e --port 8000
```

(더 단순한 확인은 루트의 `run-demo.bat`이지만 거절 동작 정도만 보입니다.)

브라우저에서 `http://127.0.0.1:8000`을 열고 아래를 확인합니다.

- [ ] 제주 지도가 보이고, 클릭하면 마커와 좌표가 표시된다
- [ ] 지도를 클릭한 뒤 `여기에 월동무 어때? 최근 시세도 같이 알려줘`를 보내면 결과가 나온다
- [ ] 결과 맨 위에 **붉은 합성 데이터 경고**가 있다
- [ ] 결과에 지도(관측소·지점 마커), 표, 한계 문구가 있다
- [ ] 차트와 흐름도가 **실제로 그려진다** (표만 나오면 CDN 로딩 실패 → 알려 주세요)
- [ ] "결과를 HTML 파일로 저장" 버튼으로 파일이 내려받아진다
- [ ] 실행 기록 패널에 사용한 데이터 / 제외한 데이터와 이유가 보인다

끝나면 터미널에서 `Ctrl+C`로 끕니다. (포트가 이미 쓰이고 있다는 오류가 나면 이전 서버가 아직 켜져 있는 것입니다.)

## 3. 실제 GPT-4o로 앱 돌리기

`.env`에 `OPENAI_API_KEY`를 넣은 뒤, 루트의 `run.bat`을 더블클릭하거나 아래 명령을 씁니다.

```powershell
cd backend
..\.venv\Scripts\python.exe -m jejuagent
```

(브라우저가 자동으로 열립니다. 주소는 `http://127.0.0.1:8000`)

### 시나리오별 기대 결과

각 시나리오를 입력해서 **기대 결과와 다르면** 실패입니다. 실패하면 4번의 방법으로 기록을 보내 주세요.

| # | 입력 | 기대 결과 |
|---|---|---|
| 1 | `주식 추천해줘` | **불가**로 끝나고 쓸 수 있는 데이터가 없다는 이유가 보인다(별도 도메인 판정은 없고 데이터 선택 단계에서 걸러짐) |
| 2 | 지도를 클릭하지 않고 `내 밭에 월동무 심어도 돼?` | 위치가 필요하다고 **한 가지만 되묻는다**. 이후 지도를 클릭하고 `여기요`를 보내면 이어서 진행한다 |
| 3 | 지도를 제주도 육지에서 클릭 + `여기에 월동무 어때? 최근 시세도 같이 알려줘` | 지도 형식 결과. 지점 고도, 고도 보정 기온 지표, 시세 추세, 합성 경고, 한계 문구. **재배 적합도 판정은 나오면 안 된다** |
| 4 | (위치 없이) `뭘 늘리면 좋을까?` | 채소재배현황 기반 작목별 **면적당 조수입** 순위 보고서. 지도 없음. 한계(도 전체 단위, 조수입 기준·순이익 아님, 2021년 자료)와 "수익을 보장하지 않는다"가 보인다 |
| 5 | (위치 없이) `마늘이랑 양파 중 면적당 조수입이 나은 건?` | 같은 데이터. 마늘(구마늘·잎마늘)과 양파(조생·만생)가 별도 작목이라 묶어 읽어야 한다. GPT-4o가 비교 대상을 제대로 고르는지 확인 |
| 6 | 제주시 지점 클릭 + `여기 감귤 생산 현황은?` | 감귤 데이터가 **서귀포시뿐**이라 이 지점에는 답할 수 없다는 안내. 일부만 답한 결과 |
| 7 | 바다(제주 앞바다)를 클릭 + 아무 질문 | **범위 밖** 안내 |
| 8 | `농사 지으면 얼마 벌 수 있어?` | 수익은 보장할 수 없다는 안내와 함께 가능한 분석을 제시 |
| 9 | `제주 채소 데이터는 뭐가 있어?` | 정답이 애매한 질문. 관련 데이터를 골라 설명하는지만 본다 |
| 10 | `내일 제주 날씨 알려줘` | 데이터가 없어 **불가**. 필요한 데이터 안내 |

### 매 시나리오마다 같이 볼 것

- [ ] 실행 기록 패널에 **사용한 데이터와 제외한 데이터, 그 이유**가 있다
- [ ] 결과의 **숫자가 표나 차트의 값과 일치**한다 (LLM이 숫자를 지어내지 않았는지)
- [ ] 합성 데이터를 썼다면 붉은 경고가 최상단에 있다
- [ ] 같은 질문을 두 번 보내면 두 번째가 더 빠르다 (분석 모듈 재사용)
- [ ] 응답이 너무 오래 걸리지 않는다 (상한: 실행 전체 5분)

## 4. 문제가 생겼을 때 기록 남기기

- 실행 기록은 프로젝트 루트의 `runs/<실행id>/trace.json`, 결과 HTML은 `runs/<실행id>/result.html`에 저장됩니다. (`runs/`는 git에 올라가지 않습니다.)
- 문제 질문 하나에 대해 아래를 모아 주세요: ① 입력한 문장과 클릭 위치, ② 화면에 나온 결과 또는 오류, ③ 해당 `trace.json`.
- `trace.json`에는 단계별 입력·출력, LLM 호출 정보(토큰, 시간), 데이터 선택·제외 결정, 코드 시도와 실패 분류가 들어 있습니다. 키는 들어 있지 않도록 만들었지만, 보내기 전에 한 번 검색(`sk-`, `key`)해 확인하세요.
- 분석 모듈 저장소 초기화(재사용 때문에 이전 결과가 섞인다고 의심될 때): `module_store/` 폴더를 지우세요. 시드 모듈(사람이 검토한 모듈)은 별도 폴더라 지워도 됩니다.

### 자주 만나는 오류

| 증상 | 원인과 해결 |
|---|---|
| `OPENAI_API_KEY가 없습니다` | `.env`가 프로젝트 **루트**에 있고 키가 들어 있는지 확인. 값 앞뒤 공백·따옴표 없이 |
| 포트 8000이 이미 사용 중 | 이전에 띄운 서버가 살아 있음. 그 터미널에서 `Ctrl+C` |
| 화면은 뜨는데 요청이 실패 | 서버 터미널이 켜져 있는지 확인. 지도가 비어 있으면 인터넷(지도 타일) 확인. 화면 코드를 고쳤다면 `npm run build` 후 새로고침 |
| 결과는 나오는데 지도·차트가 비어 있다 | CDN(unpkg, jsdelivr) 접속 불가일 가능성. 네트워크 확인. 표는 읽혀야 한다 |
| 한글이 깨져 보인다 | PowerShell 출력 인코딩 문제일 가능성. 결과 HTML 파일을 브라우저로 직접 열어 확인 |
| 질문마다 시간이 아주 오래 걸린다 | LLM 호출 수가 많은 경우. `trace.json`의 `llm_call` 개수와 시간 확인 |

## 5. 평가 도구로 한꺼번에 돌리기 (47개 질문)

화면에서 하나씩 보는 대신 질문 54개를 일괄로 돌려 지표를 봅니다. 자세한 설명은 `docs/eval.md`에 있습니다.

```powershell
# 1) 드라이런 (가짜 LLM, 무료, 약 2분). 도구가 도는지만 확인. 지표는 의미 없음
.venv\Scripts\python.exe eval\run_eval.py --llm fake --out eval\results\dry

# 2) 소량 (실제 GPT-4o, 5개). 실행 전에 예상 비용을 보여주고 y/N을 묻는다
.venv\Scripts\python.exe eval\run_eval.py --llm openai --limit 5

# 3) 전체 (실제 GPT-4o, 54개)
.venv\Scripts\python.exe eval\run_eval.py --llm openai

# 4) 재현성 검사 (LLM 호출 없음)
.venv\Scripts\python.exe eval\repro_check.py

# 5) 결과로 리포트 다시 만들기
.venv\Scripts\python.exe eval\report.py eval\results\<폴더>
```

- **예상 비용**: 전체 약 $1.2~8 (대략 1,700~11,000원). 이것은 공개 단가 기준 어림값입니다. 실제 청구액은 OpenAI 대시보드에서 확인하세요.
- 소량(`--limit 5`)을 먼저 돌려 **프롬프트·스키마 오류가 있는지** 보고 전체를 돌리세요.
- 결과는 `eval/results/`(git 제외)에 쌓입니다.
- 질문의 정답이 틀렸을 수도 있습니다. 지표가 낮게 나오면 시스템 문제인지 정답 문제인지 질문별로 확인하세요. 정답이 애매한 11개(`ambiguous`)는 별도 집계됩니다.
- 지점 기온 교차검증 오차는 **합성 데이터 기준**이라 실제 성능이 아닙니다.

## 6. 실데이터로 바꿔 테스트하기 (키 필요)

현재는 합성 샘플이라 시세·기온 숫자에 의미가 없습니다. 허브 거래 데이터는 키로 실데이터를 받을 수 있습니다.

1. `.env`에 `JEJU_HUB_PROJECT_KEY=`를 채우고 `JEJU_DATA_MODE=live`로 설정합니다.
2. 수집 (한 번 실행하면 `snapshots/live/`에 고정):
   ```powershell
   cd backend
   ..\.venv\Scripts\python.exe -m jejuagent.data.live.collect hub 20150101 20251231
   cd ..
   ```
3. 수집이 성공하면 합성 샘플보다 **실데이터가 우선** 쓰이고, 합성 경고가 거래 데이터에서는 사라져야 합니다. (지점 기온은 여전히 합성이라 그 경고는 남습니다.)
4. 실패하면 키 없음·키 오류·한도 초과·네트워크 오류를 구분한 한국어 안내가 나옵니다. 그 메시지를 보내 주세요.

**아직 실데이터로 확인하지 못한 것**: 허브 API의 실제 응답 형식(명세 문서 기준으로만 구현), 기상 일자료(농업기상 API는 명세만 있고 코드에서 호출하지 않음 — 이용조건 문의 후 결정).

## 알고 있는 한계 (테스트 중 이게 보여도 이미 알려진 것)

- 실제 GPT-4o 동작 미확인. 2번 데모와 자동 테스트는 모두 가짜 LLM
- 거래·기온 데이터는 합성. 실데이터 수집은 키가 있어야 함
- 재배 적합도와 한계온도(동해 등)는 판정하지 않음 (데이터 원칙: 공공데이터포털 + 제주데이터허브만)
- 마늘·양파·당근 등 가격 데이터와 재배현황 데이터의 **작목 이름 매핑은 월동무 하나뿐** (단가·가격 결합 분석 없음)
- 채소재배현황은 도 전체 단위·조수입 기준·2021년 자료. 지점별 차이 설명 불가
- 지도 클릭 좌표만 지원(이름으로 위치 지정 불가)
- 생성 코드 실행기는 LLM 실수를 막는 장치이지 보안 샌드박스가 아님
- DEM 90m. 경사·일사 미반영. 바다 판정은 추정이라 해안 저지대에서 오판 가능
- 센터 PC 사양(i7-8700, GTX 1060, 32GB)에서 실행해 본 적 없음
