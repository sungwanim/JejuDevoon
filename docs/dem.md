# DEM 고도 조회와 바다 판정 (티켓 10)

코드: `backend/jejuagent/geo/dem.py`. 입력: `data/(B080)공개DEM_*/*/*.img` 6장(90m, EPSG:5179, float32).

## 병합
모든 도엽이 90m 격자에 정렬돼 있고 겹치는 칸의 값이 서로 같다(실측 최대 차이 0). 그래서 보간 없이 전체 범위의 빈 격자(873x628)에 도엽을 차례로 얹고, 이미 값이 있는 칸은 그대로 둔다. 도엽이 없는 모서리 약 10%는 NaN이며 격자 밖으로 취급한다.
캐시: `.cache/dem/merged.npz`(격자+육지 마스크+도엽 서명). 서명은 도엽 이름·크기·수정시각과 마스크 파라미터다. 달라지면 자동으로 다시 만든다. 첫 실행 약 1.2초, 이후 약 0.08초. `.gitignore`에 `.cache/`가 없다(티켓 Comments 참고).

## 보간
최근접(칸 하나의 값). 칸 값 자체가 90m 평균이고, 쌍선형은 해안에서 바다 값과 섞여 마스크와 어긋난다. 경사·사면·일사는 다루지 않는다.

## 바다 마스크 기준
이 DEM은 바다 칸에도 값이 있다(전체의 약 42%가 정확히 0, 약 4%가 음수 -9.7m까지, 해안 앞바다에는 0.3~0.7m 잡음). 기준: **고도 > 1.0m인 칸의 연결 성분 중 100칸(약 0.8km2) 이상**만 육지.
- 임계값 근거: 0.5m에서는 제주항 앞바다 같은 곳의 0.5~0.7m 잡음이 육지에 붙어 바다가 육지로 판정됐다. 1.0m에서 육지 면적이 약 1,851km2로, 제주 본섬(약 1,833km2)에 우도·가파도 등을 더한 값과 거의 맞는다.
- 연결 성분 100칸 미만(작은 잡음 조각)은 육지에서 뺀다.

## 한계 (마스크가 정확한 해안선이라고 주장하지 않는다)
- 정확한 해안선 데이터가 없어 고도 임계값 + 연결성이라는 추정이다. 1m 이하 해안 저지대, 방파제·항만 매립지, 갯바위는 바다로 판정될 수 있다. 반대로 1m 넘게 값이 있는 바다 칸이 있으면 육지로 남을 수 있다.
- 90m 칸이라 해안선 오차는 최대 칸 하나(약 90m) 안팎이다. 해안 점은 신뢰하지 말 것.
- 격자에는 제주 본섬 외에 우도(약 20m)와 가파도(약 17m)가 들어 있고 육지로 판정된다(농지가 있어 막지 않았다). 마라도(남쪽 격자 밖)와 추자도(북쪽 격자 밖)는 없다.
- 격자 최고값은 1,938m(33.360N, 126.530E). 실제 한라산 정상(약 1,947m)보다 낮은 건 90m 평균 때문이다.
- DEM 파일이 없는 환경에서는 `request_plan.out_of_range`가 기존 bbox 판정으로 폴백한다(로그 경고 "폴백"). bbox는 바다를 거르지 못하고 추자도·마라도만 거른다.

## 생성 코드(티켓 05 격리 프로세스)와의 연결
05 실행기의 import 허용 목록에 `rasterio`/`pyproj`가 없고 DEM 파일을 읽을 수도 없다. 그래서 생성 코드는 `jejuagent.geo`를 직접 부르지 말고, **부모 프로세스(단계 코드)가 `get_elevation`/`is_land`로 미리 구해 데이터(프로파일/입력 dict)에 `elevation_m`, `is_land`를 담아 넘기는** 방식을 권장한다. 티켓 06의 `jejukit`이 필요하면 값을 받아 쓰는 얇은 함수로 노출하면 된다.
