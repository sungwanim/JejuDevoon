# 사용자 매뉴얼 (도민용)

이 앱은 제주의 농업 데이터(가격, 기온, 감귤 생산 등)를 불러와서, 질문에 맞게 계산하고 쉬운 보고서로 보여줍니다. 설치와 실행은 루트 `README.md`를 보세요. 이 문서는 실행된 화면을 쓰는 방법입니다.

> **꼭 알아 두세요**
> - 지금 들어 있는 가격·기온 데이터는 **합성 샘플(가짜 연습용 값)** 입니다. 결과 맨 위에 빨간 배너로 표시됩니다. 실제 시세나 실제 기온이 아니므로 농사 결정에 쓰지 마세요.
> - 이 앱은 **수익을 보장하지 않습니다.** "얼마 벌 수 있나", "무조건 이득인 작물"은 알려 드릴 수 없고, 참고할 수 있는 지표를 보여 드립니다.

## 1. 화면 구성

위에서 아래로 다음이 나옵니다.

1. **대화창:** 내가 보낸 질문과 Agent의 한 줄 응답.
2. **지도:** 제주 지도(OpenStreetMap). 클릭하면 분석할 위치가 정해지고 지도 아래에 "선택 위치: 위도, 경도"가 표시됩니다.
3. **진행 표시:** ① 요청 규격화 → ② 데이터 선택 → ③ 로드·Profile → ④ 분석 → ⑤ 렌더. 진행 중인 단계가 강조되고, 끝나면 결과 상태 배지가 붙습니다.
4. **질문 입력창:** 입력 후 Enter(줄바꿈은 Shift+Enter) 또는 [보내기]. 분석 중에는 "분석 중…"으로 바뀌고 입력이 잠깁니다.
5. **결과 영역:** 결과 HTML이 화면 안의 틀에 나오고, [결과를 HTML 파일로 저장] 버튼으로 파일로 내려받을 수 있습니다.
6. **데이터 선택 패널:** 어떤 데이터를 썼고(보조 표시 포함), 어떤 데이터를 왜 뺐는지, 답할 수 없는 하위 질문이 무엇인지.
7. **실행 기록:** 접혀 있는 패널. 단계별 내부 기록이며 전문가·개발자용입니다.

## 2. 지도 클릭하기

- 특정 장소에 대한 질문("여기에 월동무를 심으면?")이면 먼저 지도에서 그 위치를 클릭하세요. 마커가 찍힙니다. 다시 클릭하면 위치가 바뀝니다.
- 위치가 필요 없는 질문(가격 추세 등)은 클릭하지 않아도 됩니다.
- 지명이나 주소를 글로 쓰는 방식(예: "한림읍")은 좌표로 바꾸지 못합니다. 위치가 필요하면 지도를 클릭하라고 되묻습니다.
- 바다나 제주 본섬 밖(추자도, 마라도 등)을 클릭하면 "범위 밖"이라고 안내하고 분석하지 않습니다. 해안 가까이는 판정 오차(약 90m)가 있습니다.

## 3. 질문하기

질문은 평소 말투로 쓰면 됩니다. 입력창 예시 문구는 "제주 월동무 최근 가격 추세 알려줘"입니다. 다음은 질문 유형별 예시입니다. 입력창 문구와 "여기에 월동무 어때?…"는 앱의 데모·테스트에서 쓴 문장이고, 나머지는 데이터 구성에 맞춘 예시 문장입니다(실제 GPT-4o 응답은 확인하지 못했습니다).

| 유형 | 예시 | 지도 클릭 |
|---|---|---|
| 가격 추세 | 제주 월동무 최근 가격 추세 알려줘 | 불필요 |
| 지점 분석 + 시세 | (지도 클릭 후) 여기에 월동무 어때? 최근 시세도 같이 알려줘 | 필요 |
| 작목 비교 | 마늘이랑 양파 중 면적당 조수입이 나은 건? / 뭘 늘리면 좋을까? | 불필요 |
| 감귤 생산 | 서귀포시 읍면동별 감귤 생산량을 비교해줘 | 불필요 |
| 어떤 데이터가 있는지 | 어떤 데이터를 쓸 수 있어? | 불필요 |

- 쓸 수 있는 데이터는 가격·거래 통계(합성 샘플, 6개 품종, 2024년 1~3월), 서귀포시 감귤 생산 정보(읍면동별 2012~2022), 제주 채소류 재배현황(작목별 면적당 조수입·재배면적, 연산 15-16~20-21, 2021년 자료), 합성 관측소 기온(2023년) 등입니다. 이 범위를 벗어난 질문(예: 2019년 가격)은 "기간 밖"으로 빠지거나 답하지 못한다고 안내합니다.
- 쉬운 설명을 원하면 질문에 "쉽게 설명해줘"처럼 쓰세요. 앱이 요청 성격에 따라 보고서형, 그림형(큰 결론+흐름도), 지도형 중 하나로 보여 줍니다. 형식을 직접 고르는 버튼은 없습니다.

## 4. 결과 읽는 법

결과는 한 장의 문서입니다. 위에서부터:

1. **(합성 경고 배너)** 합성 샘플을 쓴 결과에는 맨 위에 빨간 배너가 있습니다. 값이 실제가 아닙니다.
2. **요약(또는 큰 결론):** 핵심 문장 몇 개. 문장 속 숫자는 계산 결과의 값과 대조해서, 근거를 찾지 못한 문장은 자동으로 지웁니다(몇 개를 지웠는지 "근거와 한계"에 표시).
3. **분석 흐름:** 질문 → 쓴 데이터 → 분석 → 결과 순서의 흐름도.
4. **결과:** 표와 차트, 지도(지점 질문일 때). 차트가 안 보이면 "표로 보기"를 펼치세요.
5. **답하지 못한 부분과 이유:** 데이터가 없어서 답하지 못한 질문. 비어 있지 않으면 응답 상태가 "일부 답변"입니다.
6. **사용한 데이터 / 제외한 데이터와 이유 / 분석 과정:** 어떤 데이터를 썼는지와 뺀 이유.
7. **근거와 한계:** 이 결과를 어떻게 해석해야 하는지(아래 5절).
8. **데이터 출처와 이용조건.**

진행 표시 옆 배지의 뜻:

| 배지 | 뜻 |
|---|---|
| 답변 완료 | 질문에 모두 답함 |
| 일부 답변 | 일부 질문은 데이터가 없어 답하지 못함. "답하지 못한 부분"을 확인 |
| 되묻기 | 정보가 모자라 Agent가 질문함(아래 6절) |
| 불가 | 이 앱이 다루는 범위가 아니라 답하지 않음(아래 7절) |
| 실패 | 분석 중 오류. 같은 질문을 다시 해 보거나 질문을 단순하게 바꿔 보세요 |

## 5. 한계 해석법

결과의 "근거와 한계"에는 상황에 맞는 문구가 자동으로 들어갑니다. 읽는 요령은 다음과 같습니다.

- **합성 샘플:** 가격·거래량·기온 값이 가짜입니다. "추세의 모양을 보는 연습용"으로만 보세요. 실데이터가 연결되면 결과가 달라집니다.
- **지점 고도와 기온 추정:** 지점의 고도는 90m 간격 격자에서 읽은 값이라 그만큼 오차가 있고, 사면 방향·경사·일사는 반영하지 않았습니다. 기온은 주변 관측소 값을 고도 차이로 보정해 추정한 값입니다(보정은 고도 1km당 6.5℃로 고정한 가정이며, 합성 데이터에서의 정확도는 실제 성능이 아닙니다).
- **한계온도 미판정:** 작물이 얼어 죽는 기온 등을 기준으로 "여기서 재배할 수 있다/없다"를 판정하지 않습니다. 극단 기온이나 저온 일수가 나오더라도 참고 지표입니다.
- **재배 적합도 미판정:** 공공데이터에 근거가 없어 적합도 판정을 하지 않습니다.
- **감귤은 서귀포시만:** 제주시 감귤 생산 데이터는 없습니다. 제주시 위치와 감귤을 함께 물으면 서귀포 데이터는 제외된다고 안내합니다.
- **재배현황은 조수입 기준:** 작목별 면적당 "조수입"은 비용을 뺀 이익이 아닙니다. 제주도 전체 단위라 내 땅이 있는 지점의 차이는 설명하지 못하고, 자료가 2021년(최신 연산 20-21)이라 오래되었습니다. 노지와 시설은 따로 순위가 나옵니다. "기타(…)" 항목은 여러 작목의 합이라 순위에서 빠집니다.
- **수익 보장 없음:** 수익을 물으면 보장할 수 없다는 안내와 함께 참고 지표로 바꿔 보여 줍니다.
- **상한:** 한 번에 LLM 호출 25회, 5분을 넘으면 그때까지의 결과만 보여 주고 "상한에 걸렸다"고 표시합니다.

## 6. 되묻기

위치가 필요한 질문인데 지도를 클릭하지 않았다면 Agent가 "어느 위치를 분석할까요? 지도에서 위치를 클릭한 뒤 다시 보내 주세요."처럼 되묻습니다(배지: 되묻기). 이때:

1. 지도에서 위치를 클릭합니다.
2. 짧게 답을 입력해 보냅니다(예: "여기요"). 화면에 "되묻기에 답하면 이전 요청과 이어서 분석합니다"라고 안내가 나옵니다.
3. 이전 질문과 이어서 분석됩니다. 브라우저 탭을 새로 열거나 서버를 재시작하면 이어쓰기 상태가 사라집니다.

## 7. 불가 안내

다음은 "불가" 배지와 이유가 나오며 분석하지 않습니다.

- 농업·기후·시장 데이터와 관련 없는 질문(예: 주식, 코인, 일상 날씨).
- 제주 본섬 밖이나 바다 위를 클릭한 경우.
- 선택할 수 있는 데이터가 하나도 없는 질문. 이때는 필요한 데이터가 무엇인지 목록으로 안내합니다.

## 8. 자주 묻는 질문

- **결과를 저장하고 싶어요.** [결과를 HTML 파일로 저장]을 누르면 `jeju-result-<번호>.html`로 내려받습니다. 차트·지도는 인터넷이 연결되어야 보입니다.
- **차트나 지도가 비어 있어요.** 인터넷 연결이나 방화벽(차트 라이브러리를 받아오는 CDN 차단)을 확인하세요. 안 되면 표·좌표 표로 대신 보입니다.
- **같은 질문을 해도 답이 조금 달라요.** 설정(temperature 0, 고정 seed)으로 줄였지만 LLM 서비스 특성상 완전한 동일성은 보장하지 않습니다.
- **개인정보를 입력해도 되나요?** 질문에 이름·연락처 같은 개인정보를 쓰지 마세요. 질문 내용은 OpenAI 서비스로 전송됩니다(`docs/submission/ai-usage.md`).
